# Hello, Watchcraft!

A redistributable referenced-local-media collection for cross-platform testing.

Download and extract this collection, then choose its folder in Watchcraft. The
nine-second video remains in the selected folder; Watchcraft records a private
reference and must never move or delete the original. The video changes from
blue to green to purple, and its chapters seek directly to each color.

The video and collection metadata are original Watchcraft test fixtures released
under CC0-1.0.
