# Hello, Watchcraft!

A redistributable local-media collection for cross-platform smoke testing.

Choose this folder in the Watchcraft desktop app. The nine-second video changes
from blue to green to purple. Clicking its three chapters should seek directly
to the corresponding color, which makes a broken local-media binding or chapter
seek obvious.

The video and collection metadata are original Watchcraft test fixtures released
under CC0-1.0.
